# ひとり旅マップ

決めた電車賃の予算と時間で行ける場所を地図に表示し、予算をできるだけ使い切る日帰りプランを作るWebアプリです。
中部地方（愛知・岐阜・静岡・長野・北陸）から中国地方（岡山・広島・山口・鳥取・島根）まで、111駅・223スポットに対応しています。

## 使い方

1. `index.html` をダブルクリックしてブラウザで開く
2. 出発駅をえらぶ（地図の駅をタップして「ここから出発する」でもOK）
3. 電車賃の予算を入れて、「往復」か「片道」をえらぶ。新幹線・特急を使うかどうかもえらぶ
4. 出発の時刻と、もどる時刻を入れる
5. 行きたいジャンルをえらぶ（または「自分で書いてさがす」にキーワードを書く）
6. 「この条件でプランを作る」を押す
7. ほかの案を見たいときは「別の案にする（再生成）」を押す
   - 条件を変えたあとに押すと、新しい条件で作りなおします

## ファイルの役割

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | 見た目 |
| `js/data.js` | データ（運賃表・駅・路線・観光スポット） |
| `js/route.js` | 運賃と所要時間の計算（いちばん良い行き方をさがす） |
| `js/planner.js` | プラン作り（予算を使い切るルートさがし・時間割） |
| `js/app.js` | 画面の動き（ボタン・地図・リスト） |

## しくみ

- **運賃**：鉄道会社ごとの「距離と運賃の表」と、駅どうしの距離から計算します。会社をまたぐときは運賃を足します。JRの特定運賃（大阪〜京都など）にも対応しています。
- **新幹線・特急**：乗った距離から特急料金を計算して、運賃に足します。新幹線は自由席、全席指定の特急（サンダーバード・はくと・やくも）は指定席の料金です。
- **バス・フェリーで行くスポット**：駅から歩けない場所（宮島、出雲大社など）は、`access` に乗り物と時間を書いています。この料金は予算にふくみません。
- **行き方**：ダイクストラ法（近い所から順に確定させていく道さがしの方法）で、安さと早さのバランスがいい行き方をえらびます。
- **予算を使い切る**：条件に合うスポットがある駅を1〜3か所つなぐルートを全部ためし、予算と時間におさまるものに点数をつけます。予算をたくさん使うほど高得点です。

## データを増やすには

- 観光スポット：`js/data.js` の `SPOTS` に同じ形で書き足します
- 駅：`NODES` に駅を足して、`LINES` の路線の中に「駅の名前と何km地点か」を書き足します

## 注意

- 運賃は2026年10月に調べた大人・きっぷの値段をもとにした目安です。遠くへ行くほど、実際とのずれが大きくなることがあります。出かける前に乗換案内で確認してください。
- お店や施設の営業時間は考えていません。
- 所要時間・歩く時間・スポットの位置は目安です。
- 地図は国土地理院の地理院タイルを使っています。
